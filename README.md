# Pillararenes

In this folder, we provide high-accuracy fixed-charge force fields for WP6 host-guest systems. 
It has been recognized that all transferable force fields are providing incorrect descriptions of pillararene dynamics. 
The impact of force-field parameters is illustrated with a series of WP6-abused-drug pairs, mimicking a practical detoxification application of macrocyclic hosts. 
The full text of the paper is available at https://pubs.acs.org/doi/abs/10.1021/acs.jctc.4c01361
